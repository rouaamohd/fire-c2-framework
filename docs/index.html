About

What is FIRE-C2?

FIRE-C2 is an open-source ns-3 simulation and multimodal dataset framework for studying stealthy backdoor attacks in wireless IoT cyber-physical systems.

Compromised sensors behave normally until fire-induced temperature conditions trigger the backdoor. The system then establishes covert C2 communication using timing-based signaling, LSB-encoded exfiltration, and a downlink command channel.

01DormantCompromised nodes look benign during normal operation.
02TriggeredA physical fire event activates malicious behavior.
03C2 activeCovert uplink and downlink communication begins.
Dataset

Multi-modal data from the full attack lifecycle.

Each simulation run exports synchronized network, node, physical, and adversarial records with ground-truth labels.
